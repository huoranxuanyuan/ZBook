# 使用指南

## 导入书籍

便携版完整解压后运行 `ZBook.exe`。点击“导入书籍”可同时选择多个文件；“导入文件夹”会扫描所选文件夹中的支持格式。也可以把文件或文件夹拖入右侧书籍区域，窗口其他区域不接收拖放。

队列最多 50 本，重复文件不重复加入。超过数量上限会拒绝本批导入；请先拆分文件夹或减少选择，避免一次扫描过多书籍。单文件上限为 64 MiB，单批总量上限为 512 MiB。超大文件和无法读取的文件会给出提示。

导入时会自动识别书名、作者、章节与分卷。文件名和正文中的元信息不一定规范，因此转换前应核对。上方显示原文件名，书名和作者可直接修改，再点击“保存信息”。

每次启动都会显示空书籍列表和空转换记录；输出目录、排版和自动封面偏好会保留。已导出的电子书不会因关闭软件而消失。

## 查看目录

有分卷的书籍默认只展开到卷名，点击卷名前的箭头显示章节；无分卷时直接显示章节。点击目录项可查看右侧正文预览。书籍列表中的“章”是识别出的章节数，不包含分卷节点和前言节点。

点击书籍列表只切换预览，不会重新分章。原文件或章节规则改变后，可对当前书点击“重新识别”，或使用书籍列表下方的“重新识别目录”处理全部列表。后者不搜索封面。

分卷由程序自动识别，不提供手动添加分卷。识别结果不理想时，可在设置中调整章节规则或自定义正则，再重新识别。章节名称可通过“章节改名”调整。

## 搜索和调整封面

“一键搜索封面”处理列表内所有书籍，包括未勾选的书籍；已有图片封面会保留。处理到哪本书，详情区就会切换到该书。搜索成功后自动采用匹配候选中的第一张图片，列表缩略图会更新。

书名相同不代表作品相同。请结合作者和缩略图核对；若存在同名作品，选择该书后点击“搜索封面”，可修改搜索词、查看其他候选或使用浏览器查找。找到原图后也可使用：

- **本地封面**：从文件选择图片。
- **粘贴封面**：读取剪贴板中的图片，不是粘贴图片网址。
- **生成封面**：使用当前书名和作者生成文字封面；在设置中选择现代青绿或暖调暮橙。

批量搜索结束后，“转换记录”会汇总未匹配封面的具体书名、原因和已使用文字封面的情况。没有高清图片时，可以使用可取得的较低分辨率图片；仍需核对内容是否正确。

设置中的“转换前自动匹配缺失封面”默认开启。关闭后会保存该偏好；单独点击搜索按钮仍会联网。明确点击“生成封面”的书籍，在直接转换时保留文字封面；再次批量搜封面可以重新尝试匹配图片。

## 导出 EPUB 或 MOBI

在右侧勾选待转换书籍，底部选择保存位置和格式。默认是 MOBI，也可选择 EPUB 或 EPUB + MOBI。内置 Kindling 编码器，无需另装 Calibre。

转换记录显示当前书籍、读取分章、封面处理、生成 EPUB 和编码 MOBI 等阶段。较长的 MOBI 编码会定时提示已用时。点击“停止”会停止后续工作，已完成的输出保留；失败原因和错误日志会保留。

同名文件自动增加编号，不覆盖已有电子书。导出的书籍包含阅读器导航目录，不额外插入需要逐页翻过的正文目录页。章节标题默认左对齐，正文默认缩进、行距等可在设置中调整。

## 数据与缓存

便携目录可写时，数据保存在旁边的 `data/` 与 `archive/`。只读目录会回退到当前用户的 `%LOCALAPPDATA%/ZBook`。开发者可通过 `ZBOOK_DATA_DIR` 指定独立的数据根目录。

| 内容 | 清理策略 |
| --- | --- |
| 封面缓存 | 保留 7 天，上限 100 MB |
| 浏览器搜索页面与日志 | 保留 7 天，上限 32 MB |
| 独立浏览器配置 | 闲置 7 天或超过 128 MB 时清理 |
| 任务日志 | 保留 30 天 |

正在使用的资源会保留。清理采用回收站；回收站不可用时保留文件。转换成功后的中间文件经输出校验后清理，正式输出不属于缓存。

## 常见问题

**导入后为什么不立刻有图片封面？**

导入负责本地识别目录。点击“一键搜索封面”批量搜图，或在转换前启用自动补搜。

**封面没有结果或搜索失败。**

检查书名和作者，查看搜索提示，尝试其他候选或“浏览器查找”。站点验证、限流和页面变化可能影响结果；也可以导入本地图片或使用文字封面。普通请求支持系统静态代理与标准代理环境变量，PAC 支持范围见[联网说明](../PRIVACY.md)。

**PDF 导入没有正文。**

扫描型 PDF 通常只有图片，需要先 OCR。程序无法替代文字识别工具；损坏或加密的文件也可能无法导入。

**拖入没有反应。**

请拖入右侧书籍区域，并检查数量上限。Windows 会限制普通权限的文件管理器向管理员权限的程序拖放；通常不需要以管理员身份运行 ZBook。

**如何提供错误信息？**

记录软件版本、输入格式、操作步骤和界面错误提示；需要附日志时，先去除私人路径、书名和个人信息。不要上传没有分享权限的完整书籍。详见[贡献与反馈说明](../CONTRIBUTING.md)。
